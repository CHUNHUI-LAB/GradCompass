# GradCompass · 找导师与项目

面向机器人与具身智能方向，整理导师研究、学位项目、申请日期、官方材料要求和有来源的申请经验。

本仓库包含 16 篇有来源的申请经验与覆盖全部案例的综合归纳。内容与检查记录见下文；线上部署状态以 GitHub Pages 对应提交及部署记录为准。

## 按要做的事浏览

- **找导师**：了解研究方向，查看学位项目或 RA 岗位。当前为 46 条机会、30 位导师；同一导师的不同机会分别展示，不把机会数当作人数。
- **找项目**：查看 MSc、MPhil、PhD 项目的申请条件与关联导师。
- **申请日历**：查已公布的截止日期、已截止轮次和待确认批次，不由未来截止推断当前开放。
- **准备材料**：当前 14 组官方材料摘要，包含原西湖 2 条及新增 12 组；明确必需、条件性、选交、未明确和未知项。
- **申请经验**：16 篇、12 个来源站点或合集的公开自述，提供逐篇总结与有案例对应的综合归纳。每张卡片只有“阅读经验”一个入口，进入同站整页阅读，最后按需打开原帖。

项目、日期和材料先打开站内摘要；经验使用 `#experiences/案例ID` 整页阅读，支持直接打开、返回列表及浏览器前进/后退。官网与原帖链接放在正文之后。原有列表 hash 地址不变。背景资格仍是底层收录条件，已移除重复资格徽章。

各页只显示实际适用的筛选：找导师保留学校、职级、研究方向、申请类型、招生信息和搜索；找项目保留学校、学位和搜索；准备材料保留学校、适用学位和搜索；申请日历只保留学校；经验不显示筛选。各页独立保存选择，返回导师页会恢复原筛选，其他页的重置不会清除它。

综合归纳明确关联已总结的16个案例；如以后新增案例，会说明哪些尚未纳入综合，不静默宣称已覆盖全部。每篇保留背景、做法、结果、适用限制、来源与商业披露。

## 材料补充与范围

`data/material-summaries.json` 单独保存 12 组官方摘要、33 个实际引用来源及逐项 sourceIds。加载时与原 `catalog.materials` 的西湖 2 条合并，共 14 组，覆盖现有 27 条已核实学位项目的材料信息，其中新增 25 条非西湖项目。

覆盖关联不代表每项要求都已明确，也不是完整申请清单。摘要保留未知项、适用年份、项目差异及官网来源。RA 使用岗位资格，尚无已核对的独立文件清单，不混入学位材料。补充文件加载失败时明确提示，保留原西湖资料与其他页面。

原始 `catalog.json`、RA、导师简介不改写。前一版的 11 篇经验原样保留，2026-10-02 扩充 5 篇。保留 32 位原始导师、10 位简介、46 条机会和对应的 30 位导师；教授/副教授/助理教授机会数分别为 6/15/25。

## 证据和隐私

新材料来源核读日为 2026-10-01；西湖原记录不假装重新核验。申请经验为结果自报，不是招生政策、录取率或个人资格依据。硕士申博经历不证明本科直博资格。

没有账户、上传、外部分析、Cookie、浏览器持久化或个人申请材料收集。筛选与比较仅驻留页面内存。无可靠公开原帖链接的经验不进入公开数据。来源版权属于原作者；未自动选择代码许可证。
