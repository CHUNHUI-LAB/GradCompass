# GradCompass

一个从可申请路径出发的研究生申请信息平台。当前发布候选版本聚焦机器人与具身智能导师、官方项目准入、截止日期及有证据的材料要求。

## 当前数据边界

- 32 条导师记录；默认显示 30 条具有已核实本科起点路径与关联的记录
- 33 条逐学位路径：27 verified、4 unknown、2 excluded
- 12 条截止/批次记录，2 条已核实材料要求，66 个有界观察入口
- 核验日期：2026-10-01；每日自动更新尚未启用
- 香港本部与广州、深圳校区分别记录；本轮并非完整院校或导师名录
- 本科可申请、无需强制推免、无已有硕士前置是制度性筛选，不代表任何个人满足全部条件或拥有录取名额
- 普通推荐信与推免资格是两件不同的事

## 运行

无需构建步骤或客户端依赖。用任意静态 HTTP 服务器打开本目录，例如 `python -m http.server 4173`，再访问本地服务。ES 模块与 JSON 读取需要 HTTP，不建议直接双击 HTML。

GitHub Pages 可以从此目录内容直接托管。所有资源使用相对路径，适用于仓库项目子路径；`.nojekyll` 避免 Jekyll 改写。仓库名称、所有者、线上 URL 与部署设置由发布方确认，本候选版本不假设域名。

## 功能

- 默认本科路径预设；学校、主题、学位、招生信号与文本筛选
- 源据可追溯的导师详情与逐学位招募声明
- 2–3 位导师/路径比较，数据仅保留在当前页面内存
- 官方截止与过期轮次分开列出，不用未来截止推断当前开放
- 独立材料要求页与核验方法/来源页

未知与排除的路径可在关闭预设后检查，永远不会被自动转换为已满足资格。导师宣传或 PhD 招募不会推导为 MPhil 名额。

## 数据

`data/catalog.json` 是规范化公开数据，来源仅限三个已审阅批次：`hkust-hku.json`、`other-hk.json`、`mainland-application.json`。公开记录保留来源 URL、核验日、路线关联、原始公开事实及不确定性，移除了私人背景与个性化优先级。

`data/catalog-test-manifest.json` 记录规范化检查结果。数据更改时应重新执行核验、测试与冻结；不能只把核验日期更新为今天。每天检查来源与每天有新增结论并不等价。

## 检查

- `npm test`：无需安装依赖的 Node 单元与 DOM 合约渲染测试
- `node tests/browser-smoke.mjs`：可选的实际浏览器检查，需要测试环境自行提供 Playwright 与 Chromium；环境变量 `TEST_URL` 可指向本地或已发布站点，`QA_OUTPUT` 指定本地报告目录
- `python scripts/freeze.py`：对明确发布文件清单计算 SHA-256，生成 `release-manifest.json`

当前逻辑/渲染测试通过。实际桌面/手机浏览器布局、焦点与截图验收尚未完成：本地环境禁止 Chromium 进程套接字，云浏览器无法打开该本地服务。见 `QA.md`。发布后应针对最终 URL 运行浏览器烟雾测试。

## 隐私与许可

没有账号、数据上传、外部分析、Cookie、浏览器持久化、后台或用户材料收集。搜索和比较在页面内运行；只有点击来源链接才前往外部站点。

本仓库未自动选定软件开源许可证。第三方论文、项目与网页的版权归各自权利人，来源链接或事实整理不授予转载权。代码许可证等待维护者明确选择。
