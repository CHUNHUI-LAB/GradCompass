## 按要做的事浏览

- **找导师**：了解研究方向，查看学位项目或 RA 岗位。本版本 123 位导师均可查阅，其中 56 位有完整研究简介。已核实个人学位关联 57 条、独立 RA 岗位 2 条；新增博士项目参考另行标注，不计入这 59 条关联与岗位。同一导师的不同关联分别展示，不把关联数当作人数。
- **找项目**：本版本 56 个项目均可查阅，已有 30 份培养与研究简介，简介覆盖 11 所学校。支持按学校、学位及正文关键词搜索；其余项目提供基本信息、证据范围及待补说明，不宣称简介全部齐备。
- **申请日历**：查已公布的截止日期、已截止轮次和待确认批次，不由未来截止推断当前开放。
- **准备材料**：本版本 17 组官方材料摘要，包含目录中的西湖 2 条及独立补充文件中的 15 组；明确必需、条件性、选交、未明确和未知项。
- **申请经验**：26 篇、19 个来源站点或合集的公开自述，提供逐篇总结与有案例对应的综合归纳。每张卡片只有“阅读经验”一个入口，进入同站整页阅读，最后按需打开原帖。

项目、日期和材料先打开站内摘要；经验使用 `#experiences/案例ID` 整页阅读，支持直接打开、返回列表及浏览器前进/后退。官网与原帖链接放在正文之后。原有列表 hash 地址不变。导师研究信息与项目参考保持可读；各条申请渠道的学历、推免及其他资格要求独立说明，不能由某一路径的条件推断导师整体是否可申请。

各页只显示实际适用的筛选：找导师保留学校、职级、研究方向、申请类型、招生信息和搜索；找项目保留学校、学位和搜索；准备材料保留学校、适用学位和搜索；申请日历只保留学校；申请经验使用独立的正文关键词搜索与作者背景筛选；综合总结不随筛选变化。各页独立保存选择，返回导师页会恢复原筛选，其他页的重置不会清除它。

综合归纳明确关联已总结的26个案例；如以后新增案例，会说明哪些尚未纳入综合，不静默宣称已覆盖全部。每篇保留背景、做法、结果、适用限制、来源与商业披露。
