# GradCompass · 找导师与项目

面向机器人与具身智能方向，整理导师研究、学位项目、申请日期、官方材料要求和有来源的申请经验。

本仓库包含 26 篇有来源的申请经验与覆盖全部案例的综合归纳。内容与检查记录见下文；线上部署状态以 GitHub Pages 对应提交及部署记录为准。

## 按要做的事浏览

- **找导师**：了解研究方向，查看学位项目或 RA 岗位。当前为 59 条机会（57 条学位机会与 2 条独立 RA）、41 位可见导师；目录保留 43 条导师记录，其中 41 位有完整研究简介。同一导师的不同机会分别展示，不把机会数当作人数。
- **找项目**：已有 27 个项目，全部补充培养与研究简介，覆盖 9 所学校，支持按学校、学位及正文关键词搜索，并保留申请条件与关联导师。
- **申请日历**：查已公布的截止日期、已截止轮次和待确认批次，不由未来截止推断当前开放。
- **准备材料**：当前 14 组官方材料摘要，包含原西湖 2 条及新增 12 组；明确必需、条件性、选交、未明确和未知项。
- **申请经验**：26 篇、19 个来源站点或合集的公开自述，提供逐篇总结与有案例对应的综合归纳。每张卡片只有“阅读经验”一个入口，进入同站整页阅读，最后按需打开原帖。

项目、日期和材料先打开站内摘要；经验使用 `#experiences/案例ID` 整页阅读，支持直接打开、返回列表及浏览器前进/后退。官网与原帖链接放在正文之后。原有列表 hash 地址不变。背景资格仍是底层收录条件，已移除重复资格徽章。

各页只显示实际适用的筛选：找导师保留学校、职级、研究方向、申请类型、招生信息和搜索；找项目保留学校、学位和搜索；准备材料保留学校、适用学位和搜索；申请日历只保留学校；申请经验使用独立的正文关键词搜索与作者背景筛选；综合总结不随筛选变化。各页独立保存选择，返回导师页会恢复原筛选，其他页的重置不会清除它。

综合归纳明确关联已总结的26个案例；如以后新增案例，会说明哪些尚未纳入综合，不静默宣称已覆盖全部。每篇保留背景、做法、结果、适用限制、来源与商业披露。
