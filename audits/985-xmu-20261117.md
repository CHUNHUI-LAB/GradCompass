# 厦门大学逐人增补（2026-11-17）

新增40位机器人、三维视觉、导航、控制与感知研究人员，总1275位导师、108条参考路径。4位有近五年首次本校非博士后教研任职证据；24位在2027博士招生资格名单列名。本轮未核到新增明确2028个人招募。学校新学院、导师身份、年度资格和个人招生分开处理。

覆盖：新人工智能学院44位专任目录及20位定向个人页；信息/软件方向定向核读；旧航空14页111名、机电博导21名及新智能制造学院70名作为候选入口，逐人筛具体机器人任务。非全部候选主页穷尽，也非全校穷尽。

[2027资格名单](https://gs.xmu.edu.cn/info/1611/58252.htm)附件按姓名与单位核对；[2027专业目录](https://zs.xmu.edu.cn/info/1063/37272.htm)本身不列导师，不能当逐人名单。2026-11-17发布[第二批资格申请通知](https://gs.xmu.edu.cn/info/1611/58872.htm)，未列名不等于永久无资格。2027资格不能外推2028接收或当前余位。

智能制造学院2026年9月成立，结合新官网目录与资格表记录归属，不把转院当新入职。王振忠按资格表仍列航空；喻骁2019.12首任、王振忠2011.03非2009博士后、郭景华2015.10、袁飞2008.07均保留原首任。林逸晗等时间未知不补猜。

张亚超、敖晟、苏松志、晁飞及其他仅硕导或泛研究生招募者进入研究目录时，不挂未经确认的个人博士路径。研究内容取自公开任务/论文条目，不冒称论文全文验证、学生设备保证或个人适配评级。

补充交叉核验：敖晟计算机系官网明确2025年2月加入厦大，故补记月精度首次本校任职；当前人工智能学院归属不因历史介绍回退。硕导与博士资格未知分别保留，近五年首任共4位。来源：https://cs.xmu.edu.cn/info/1045/3050.htm
