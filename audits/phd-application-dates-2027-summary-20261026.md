# 2027年博士申请日期核查（2026-10-26）

本轮核查现有导师目录涉及的20所学校，优先机器人相关院系。2027指入学年，申请可能在2026年进行；春季与秋季、普通申请考核与推免直博、校内转博、实验室筛选、材料节点分开。仅覆盖下表列明的渠道，不能视为全校所有院系和专项均已查全。

在网站「截止日期」点击**筛选2027年博士申请日期**，再选学校；也可直接选择PhD并输入2027。现有75条学位日期记录中，58条匹配2027博士（含历史轮次和待核项）；本轮新增44条，其中36条有具体截止日，8条保留空截止。

已公布日期不代表实际提交系统已登录验证、导师有余位或个人获录取。时刻与时区只按来源记录，未注明的不补成23:59。城大本次重读受阻，沿用10月3日已核日期，单列其时效。
